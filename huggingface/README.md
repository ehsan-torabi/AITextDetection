# AITextD — Persian AI-Generated Text Detection Models

Trained checkpoints for the [AITextDetection](https://github.com/ehsan-torabi/AITextDetection)
project: detecting whether **Persian** text was written by a human or generated by AI.

This repository mirrors the `models/` directory of the source project one-to-one, so a
single download drops every serving artifact into place:

```bash
# from the project root, after cloning the GitHub repo
hf download ehsantorabi/aitextd-models --local-dir models/
```

## What is inside

Sixteen registered models cover four families — classical ML on TF-IDF (+ stylometric
features), deep networks trained from scratch, fine-tuned LLMs, and a System One
decision model — plus the shared serving artifacts (`tfidf_vectorizer.joblib`, the
GPT-2 and ParsBERT tokenizers, the raw Persian GPT-2 LM used for the training-free
perplexity signal, and the fine-tuned Laya decision model). The weighted **ensemble**
is computed live by the serving stack from these checkpoints; it is not a file.

## Artifacts not included

- `models/laya_multilingual/` — the untouched
  [convaiinnovations/laya](https://huggingface.co/convaiinnovations/laya) *multilingual*
  (mmBERT-base) base checkpoint; only needed to re-run the fine-tuning notebook, so it is
  not duplicated here. Serving uses the fine-tuned `laya_persian/` above.
- `models/laya_persian/checkpoint_latest/` — a redundant mid-training checkpoint of
  `laya_persian` (identical final weights); skipped.

## Evaluation protocol

Metrics above are test-set results from the project's leak-free v2 protocol
(group-aware splits, paraphrase-attack and domain-shift conditions). Frozen evidence,
per-model confusion matrices and full tables live in the GitHub repo under `reports/`
and `models.json`.

## Base-model attribution

- ParsBERT classifier → [HooshvareLab/bert-fa-base-uncased](https://huggingface.co/HooshvareLab/bert-fa-base-uncased)
- GPT-2 classifier + perplexity LM → [HooshvareLab/gpt2-fa](https://huggingface.co/HooshvareLab/gpt2-fa)
- Laya System One decision model → [convaiinnovations/laya](https://huggingface.co/convaiinnovations/laya) (multilingual, Apache-2.0)

## Usage

The checkpoints are consumed by the project's FastAPI serving stack (`aitextd/`,
`models.json`), not by a single `pipeline(...)`. See the
[GitHub repo](https://github.com/ehsan-torabi/AITextDetection) for the serving API,
the six training notebooks, the web front end and tests:

```bash
uv sync
hf download ehsantorabi/aitextd-models --local-dir models/
uv run python server.py          # API on :8000
```
